# 演習1：起動し、画面を変え、保存を確かめる

[第1回教材](../lessons/01-overview.md)

前提：Node.js 24、教材フォルダ、ブラウザ。`.env` を作った場合は `APP_MODE=demo` にします。操作対象はローカルの学習用ファイルです。

## A. 起動と基本操作（15分）

1. `package.json` がある場所で `npm start` を実行。
2. http://localhost:3000 を開く。
3. 「教材を開く」「APIを観察する」「完成を説明する」の3件を追加。
4. 1件目を完了にし、「未完了」を押す。2件だけ出ることを確認。
5. 「すべて」に戻し、2件目を「通信を観察する」へ編集。
6. 3件目を削除。最初は確認ダイアログでキャンセルし、残ることを確認。もう一度削除して確定。

期待する結果：2件残り、1件が完了。未完了の件数は1。画面が出なければターミナルのURLとエラーを確認します。

## B. 実画面と3ファイルを対応させ、見出しと色を変える（20分）

最初の5分で[図解教材](../browser-and-frameworks.md)の実画面と操作前後を見ます。見出し＝HTML、色＝CSS、保存依頼・件数更新＝JavaScriptを指し、タスクの行がJavaScriptで作られることを確認します。残り15分で次を操作します。

1. `app/public/index.html` と `style.css` をエディターで開き、コピーを別名で自分の練習フォルダへ保存。
2. `index.html` の `<h1>マイタスク</h1>` の文字を `<h1>わたしの学習ノート</h1>` に変更。
3. 保存してブラウザを再読み込み。大きな見出しが変わることを確認。
4. `style.css` 冒頭の `--accent: #266b53` を `--accent: #315b8a` に変更。`--accent-dark` も `#244466` にすると、ボタンにカーソルを置いた色が揃います。
5. 保存して再読み込み。ボタンや強調文字が青になることを確認。
6. 見出しと色を元の値へ戻すか、変えた値を記録して残します。以降の教材のアプリ名「マイタスク」は元の名前を指します。

つまずいたら：保存済みか、同名の別フォルダを編集していないかを確認。HTMLファイルを直接ダブルクリックせず、`http://localhost:3000` を開きます。HTMLの括弧やCSSの `;` を消した場合はコピーから戻します。

## C. 保存先を見る（10分）

1. `app/data/tasks.json` を**読むだけ**で開く。`title` にタスク名、`done` に `true` または `false` があることを確認。
2. ブラウザを再読み込みし、2件が残ることを確認。
3. ターミナルで `Ctrl+C`、続けて `npm start`。再び画面を開き、2件が残ることを確認。
4. サーバー停止中に「一覧を再読み込み」を押し、通信できないというメッセージを観察。起動し直して再試行。

期待する結果：ブラウザやサーバーを再起動しても、ファイルに残ったデータを読み直せる。保存ファイルを開けない場合は、少なくとも1件追加したか確認します。手でJSONを壊した場合は[トラブル対応](../troubleshooting.md)へ。

## D. ブラウザにも保存する（15分）

[保存の実験](01-browser-storage.md)へ進みます。メモリ・sessionStorage・localStorageの違いを観察し、このアプリのタスク保存と区別します。
