# 用語集

[教材の入口](../README.md)

| 言葉 | この教材での意味 |
| --- | --- |
| ブラウザ | Chromeなど、Webの内容を受け取って表示・操作するアプリ |
| DOM | ブラウザが扱う、見出しやボタンなどの要素の構造 |
| レンダリング | コードやデータから表示内容を作る処理。文脈により部品の計算や描画を指す |
| React | 画面を部品に分けて作るJavaScriptのライブラリ |
| コンポーネント | 画面などを組み立てる再利用可能な部品 |
| JSX | JavaScriptにHTMLに似た記法を書ける拡張。通常はJSへ変換して使う |
| ビルド | コードを配信・実行できる形に準備する処理 |
| Next.js | Reactを土台にページやサーバー処理などをまとめたフレームワーク |
| ハイドレーション | 既にあるHTMLの画面へJavaScriptの操作処理を結び付けること |
| ログインのセッション | 本人確認した利用者として継続して扱う状態・期間 |
| キャッシュ | 読み込みなどを速くするために再利用するデータ |
| Webアプリ | ブラウザを画面として使うソフトウェア |
| フロントエンド | 人が見て操作する画面と、その動き |
| バックエンド | 画面からの依頼を受けて処理する部分 |
| サーバー | 依頼を待って処理するプログラムやコンピューター |
| DB／データベース | 情報を整理して保存・検索する仕組み |
| HTML | 見出し、入力欄など画面の構造を書く言語 |
| CSS | 色、大きさ、余白など見た目の指定 |
| JavaScript | 動作を記述するプログラミング言語 |
| Node.js | JavaScriptをブラウザ以外で動かす実行環境 |
| npm | Node.jsのプロジェクトの操作やパッケージを扱う道具 |
| LTS | 長期保守されるリリース |
| localhost | 自分のPCを指す名前 |
| ポート | サーバーが依頼を待つ窓口番号。今回は3000 |
| API | プログラム間で決まった形式の依頼を受ける窓口 |
| HTTP | Webで依頼と応答をやり取りするルール |
| メソッド | GETやPOSTなど、HTTPで何をするかの指定 |
| JSON | 項目名と値を組にして渡すデータ書式 |
| ステータスコード | 処理結果を示す番号。例：200は成功 |
| バリデーション | 入力がルールを満たすかの確認 |
| CRUD | 作成・読取・更新・削除という基本操作の総称 |
| SQL | DBの表や操作を指示する言語 |
| テーブル・行・列 | 情報の表、1件の情報、情報の項目 |
| UUID | 重複しにくい長い識別番号 |
| 認証 | 誰が利用しているかを確かめること |
| 認可 | その人にどの操作を許すかを確かめること |
| RLS | DBの行ごとにアクセス条件を確かめる仕組み |
| トークン | ログイン済みであることなどを証明する文字列 |
| 環境変数 | 実行時にプログラムへ渡す設定。開発では.envに記載 |
| Git | ファイルの変更履歴を記録する道具 |
| GitHub | Gitの保管場所をオンラインで共有するサービス |
| リポジトリ | プロジェクトのファイルと履歴の保管場所 |
| 差分 | 変更前後の違い |
| コミット | 変更をひとまとまりの履歴として記録すること |
| push | 手元のコミットをリモートの保管場所へ送ること |
| PR | 変更を取り込む前に確認してもらう提案（Pull Request） |
| デプロイ | プログラムを動かす環境へ配置すること |
| コンテナ | アプリと実行環境をまとめて動かす仕組み |
| リージョン | クラウドの設置地域 |
| 受け入れ条件 | できたと判断するための具体的な条件 |
| 回帰確認 | 変更後にも既存機能が壊れていないか確かめること |


| 言葉 | この教材での意味 |
| --- | --- |
| ストレージ | データを置く場所 |
| メモリ | 実行中のプログラムが一時的に値を置く場所 |
| オリジン | 通信方式・ホスト名・ポートの組。ブラウザ保存などの区切り |
| localStorage | 同じブラウザ・オリジンで値を保存する仕組み |
| sessionStorage | 同じオリジンのタブ内で値を保存する仕組み |
| IndexedDB | ブラウザに構造を持つデータを保存する仕組み |
| Cookie | 条件に合うHTTP要求へ自動送信される小さなデータ |
| HTTPS | 暗号化されたWeb通信 |
| Cloud Run | Google Cloudでアプリのコンテナを動かすサービス |
| リビジョン | Cloud Runに配置したコードや設定の版 |
| IAM | クラウドの操作や呼び出し権限を管理する仕組み |
| Cloud Build | ソースから実行用イメージを作るサービス |
| Artifact Registry | 実行用イメージなどを保存するサービス |
